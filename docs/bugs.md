## Rules for AI-assisted debugging
1. Read the relevant bug entry and inspect the referenced code first.
2. State the leading hypothesis and alternatives before editing.
3. Prefer the smallest change that addresses the demonstrated cause.
4. Add a regression test when feasible.
5. Run the relevant test and report the actual result.
6. If the hypothesis fails, update the entry rather than stacking speculative edits.
